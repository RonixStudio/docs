  <Tab title="Installation">
    <Steps>
      <Step title="Step 1">
        Download the resource from BuiltByBit or Polymart.

        <Note>
          Your server version should be 1.19 or above.
        </Note>
      </Step>
      <Step title="Step 2">
        You should install the necessary plugins before installing the resource.

        <Note>
          If you installed _necessary plugins_ before you don't need to do this step. Backup your configuration files before setup the configuration.
        </Note>
      </Step>
      <Step title="Step 3">
        Stop your server and make sure you meet the necessary requirements.
      </Step>
      <Step title="Step 4">
        Open the zip file of the product and place the "plugins" folder into the root directory of your server.
      </Step>
      <Step title="Step 5">
        Restart your server and the process is complete\!
      </Step>
    </Steps>
