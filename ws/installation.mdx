<Steps>
  <Step title="Step 1">
    Download the resource from BuiltByBit or VoxelShop.

    <Note>
      Your server version should be **Paper 26.2+**
    </Note>
  </Step>
  <Step title="Step 2">
    You should install the necessary plugins before installing the resource.

    <Note>
      If you installed _necessary plugins_ before you don't need to do this step. Backup your configuration files before setup the configuration.
    </Note>
  </Step>
  <Step title="Step 3">
    Stop your server and make sure you meet the necessary requirements.
  </Step>
  <Step title="Step 4">
    Put the jar into `plugins/`**.**
  </Step>
  <Step title="Step 5">
    Start the server once, then stop it.\*\* \*\*WandererShop creates `plugins/WandererShop/`. With no license key yet it prints a framed `LICENSE VERIFICATION FAILED` block and turns itself off. That is expected.
  </Step>
  <Step title="Step 6">
    Set three values in `config.yml`\*\*. \*\*A name for this server, your economy plugin, and your license key:

    ```text
    server-id: "survival"                  # lowercase letters, digits, - and _; the license binds to it
    
    economy:
      vault:
        expected-provider: "Essentials"    # your economy plugin (see Economy setup)
    
    license:
      key: "WS-XXXX-XXXX-XXXX-XXXX"        # the key you received
    ```
  </Step>
  <Step title="Step 7">
    Start the server. The console shows `License verified` and `WandererShop ready`.
  </Step>
  <Step title="Step 8">
    Open your first market. Run `wanderershop admin event start 1h` in the console. Players open it with `/ws`.

    Next, make the offers your own in `pool.yml`, then run `/ws admin validate` and `/ws admin reload`. For automatic markets, turn on a schedule.
  </Step>
</Steps>
