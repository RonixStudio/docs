`/wanderershop` also answers to `/ws` and `/wshop` (`commands.aliases`). `/ws help` shows each player the commands they may use; anyone with an admin permission also gets `/ws admin help`. Every command in those lists is clickable: one that only shows something runs, one that changes something goes into the chat box first.

> **For Players:**

| **Command** | **Permission** | **What it does** |
| --- | --- | --- |
| /ws | wanderershop.use | Opens the market. |
| /ws mailbox, /ws mail | wanderershop.mailbox | Collects the rewards waiting in the mailbox. |
| /ws about | wanderershop.use | Version, developer and website. |
| /ws help | any of the above | The commands you may use, clickable. |

- **Durations:** `30m`, `2h`, `1d12h`, `3d`; from one minute to 30 days.
- **Confirmation:** a command that changes something waits for `confirm`. Without it, it prints the full command to confirm.
- `<player>`**:** an online name, a UUID, or the last name of a player who has opened the market on this server.
- **Console:** every admin command also runs from the console, without the slash.
